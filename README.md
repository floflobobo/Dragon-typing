# Dragon Clavier

Jeu pour apprendre aux enfants du primaire (CP à CM2) à taper au clavier AZERTY avec leurs 10 doigts, dans un univers de dragons.

## Contenu

- **15 leçons guidées** : des touches repères F et J jusqu'aux lettres accentuées et aux phrases, avec le doigt à utiliser affiché à l'écran.
- **La pluie d'œufs** : taper la lettre de chaque œuf avant qu'il touche le sol.
- **La course des dragons** : taper des mots pour battre le dragon rival.
- **Le défi chrono** : un maximum de mots en 60 secondes.
- **Mon grimoire** : précision, vitesse, touches difficiles et entraînement sur mesure.

Bruitages et aide vocale (lecture de la lettre quand l'enfant hésite) activables dans les Réglages. La progression est enregistrée dans le navigateur (localStorage).

## Utilisation

Ouvrir `index.html` dans un navigateur. Aucun serveur ni installation n'est nécessaire.
